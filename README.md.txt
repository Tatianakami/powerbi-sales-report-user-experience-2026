# 📖 About

This project was developed as part of the **Digital Innovation One (DIO) Power BI Analyst Bootcamp**.

The objective was to redesign an existing Power BI report by applying User Experience (UX) concepts, improving navigation, layout, readability, visual hierarchy, and dashboard usability.

The report was reorganized to provide a cleaner and more intuitive experience while preserving the original business information.

---

# 🎯 Objectives

- Improve dashboard usability
- Apply UX best practices
- Improve navigation between pages
- Improve visual hierarchy
- Create a cleaner layout
- Organize dashboard components
- Enhance data readability
